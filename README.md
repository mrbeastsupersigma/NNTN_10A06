# Núi lửa phun trào — Website trình chiếu

Website trình chiếu 13 slide bằng tiếng Việt, thiết kế tông đen–đỏ, có điều khiển bằng phím mũi tên, nút chuyển trang, chấm điều hướng, chế độ toàn màn hình và hỗ trợ vuốt trên điện thoại.

## Cách sử dụng
- Mở `index.html` trong trình duyệt hoặc bật GitHub Pages cho nhánh `main`, thư mục `/(root)`.
- Nhấn `→` / `Space` để sang trang, `←` để quay lại; `Home` / `End` tới trang đầu/cuối.
- Nút ⛶ để bật toàn màn hình.

## Nội dung
Bản chất magma và nguyên nhân phun trào; kiểu phun trào; dấu hiệu cảnh báo; tác động tới con người, hệ sinh thái, khí hậu và kinh tế; ứng phó và bảo vệ hô hấp; lợi ích sau phun trào; các vụ phun trào lịch sử.
